## 实质变化

### 1. 子代理 activation 与 SDK 完成协议

**官方说明＋源码核实。** 子代理执行和通知统一，工具先返回 child ID；服务端新增 `session/wait` 并等待受管理后代及其后续根活动。自定义 SDK runtime 必须提供该方法。公开高层 `HarnessSession.run()` 仍以根首次 idle 收集返回，不能与新 wait 的完整子树语义混用。

**判断：验证／借鉴，P1。** 自建 SDK wrapper 需要核对接收、等待、通知消费和进程释放顺序；业务“完成”需另有明确定义。[wait 实现](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/sdk/server/src/server.ts#L214)、[SDK 说明](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/sdk/client/README.zh.md)、[嵌套完成 commit](https://github.com/deepseek-ai/deepseek-harness/commit/50da6f0b168d3bb1fe85ed3f8f20fd2a918a7d26)。

### 2. Agent Team 由 outbox 改为直接 inbox 投递

**官方说明＋源码 diff 核实。** 旧 mailbox 实现删除，自动重试、重发去重及 `maxPendingMessagesPerMember` 移除；发送返回 `messageId`。持久 roster／任务和 CAS 仍在，接收确认不等同模型处理完成或独立同步 flush。

**判断：观察／验证，P1。** 对依赖旧结果字段和交付语义的接入是迁移项。重试与幂等应重新分配给业务层或消息系统。[Team 说明](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/experimental/agent-team/README.zh.md)、[当前服务](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/experimental/agent-team/src/index.ts)、[变更 commit](https://github.com/deepseek-ai/deepseek-harness/commit/c772c85c173d6727504195f7a3d8546a23de259f)。

### 3. Python PTC 纳入 Session 文件策略；both 模式删除

**官方说明＋源码核实。** 实验性 Python runtime 注入 `sandbox` 与 `sandboxPolicy`，受限模式经 `confine()` 启动；自定义组合必须提供这些服务。核心工具类型与 schema 从 native／ptc／both 收窄为 native／ptc。

**判断：验证，P1。** 旧配置、API 和自定义 runtime 需迁移；不能将文件策略扩展解读为网络或多租户隔离保证。Python runtime 无随附 profile 默认启用，能力增加不是默认执行方式改变。[Python runtime](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/experimental/ptc-runtime-python/src/index.ts#L745)、[包限制](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/experimental/ptc-runtime-python/README.zh.md)、[工具类型](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/core/tools/src/types.ts)。

### 4. 空闲超时与取消后的收尾可靠性

**官方说明＋源码 diff 核实。** idle watchdog 不再完全依赖传输自行观察 abort；超时可直接结束等待中的 iterator demand，适配器避免等待已经被传输遗弃的 generator drain。当前代码包含后续的按 demand deadline 处理调整；应以本 tag 的实现为准。

**判断：借鉴／验证，P1。** 值得关注的不是泛化“支持取消”，而是请求能否按期限返回、资源是否收尾、外部效果是否已发生。上游 commit 描述的压力测试不计作本项目实测。[修复 commit](https://github.com/deepseek-ai/deepseek-harness/commit/dbb150ff0e589ec5b34a261c201a853affe71a29)、[后续调整](https://github.com/deepseek-ai/deepseek-harness/commit/99670bab728b8cd3803bf02de29c83937abe58f3)、[当前 timeout 源码](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/util/timeout/src/index.ts)。

release 还列出关闭 watcher 异常、Agent 资源释放时序、Windows PTY 和持久 PowerShell 等修复；本轮只作官方报告记录，没有逐平台复现。[当前发布](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.2)

### 5. Session 工作目录、Worktrees 与共享指令目录

**官方说明＋固定源码／文档核实。** 新增 `working_directory` 及 TypeScript/Python SDK 目录 API；实验 Worktrees 从本地提交新建分支和 checkout 后进入同一 Session。改变当前目录不修改原始项目标识、沙箱授权或已有进程目录，Worktree 不复制未提交文件，退出或部分失败也可能保留产物。共享 `AGENTS.md` 可通过 `DSH_AGENTS_HOME` 选目录；旧 agent-instructions 逐行 `dshHome` 配置移除。

**判断：借鉴／观察，P2。** 有助于任务隔离和项目指令复用，但不是自动权限隔离或清理系统。[工作目录](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/session/working-directory/README.zh.md)、[Worktree](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/experimental/worktree/README.zh.md)、[目录集中化 commit](https://github.com/deepseek-ai/deepseek-harness/commit/79bd3d8da7d53adf28042b3a33fbf98e8c0c5ee7)。

### 6. 插件与模型组合继续扩展

**官方说明；关键配置／差异核对。** Official 列表提供与运行版本匹配的 Claude Code／Codex 按需组合包；它们可用于 Headless、SDK、ACP。默认 SDK persona 变为通用 Agent。pi-ai 升至 1.0.2，动态系统提示词及工具更新按模型能力处理。实验插件新增 Session 状态记录接口，不能将其泛化为企业状态存储或完整持久化保证。

**判断：观察／验证，P2。** 有利于把 harness 用于编码之外的任务，但模板身份变化不证明新业务能力。对模型网关和树外插件应锁定版本、核对加载及能力声明。[插件管理](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/boot/plugin-manager/README.zh.md)、[pi-ai](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/llm/llm-pi-ai/README.zh.md)、[persona 变更](https://github.com/deepseek-ai/deepseek-harness/commit/3e373fd78574aa73154c259de58a054343bd7af5)、[锁文件](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/pnpm-lock.yaml)。

### 7. Web 监听与执行可观察性

**官方说明＋固定文档核实。** Web 支持具体监听地址及原生 HTTPS；Trajectory 修复了等待、流式输出、重试和压缩状态显示，后台工作也不再仅因父步骤正常结束就被标成中断。HTTPS 配置的运维责任和状态 UI 的准确性分别评估。

**判断：验证，P2。** 有利于自托管与排障，但不是 SSO、可靠任务终态或审计合规的交付证明。[部署指南](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/docs/user/guide/public-deployments.zh.md)、[状态修复 commit](https://github.com/deepseek-ai/deepseek-harness/commit/0a447b374e2dd923f96f94d043878baeda50d62c)、[后台任务显示修复 commit](https://github.com/deepseek-ai/deepseek-harness/commit/bb5a418654bc1d473c425c9bcebcd9c6645202e9)。

### 8. 附加外发与依赖变化

实验性思考翻译可使用 Bing、Google 或付费 DeepSeek Flash。**官方说明：**启用这些功能涉及独立服务及可能的额外成本。**推断：**企业需把待翻译内容的出站路径加入检查，不能只审核主模型路由。[当前 release](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.2)

锁文件和包差异确认运行、协议、图像与渲染依赖发生变更，pi-ai 为 0.87.1→1.0.2。官方将一部分更新描述为兼容范围的安全修复；本项目没有据此声称具体 CVE 已修复，也没有运行依赖审计。[锁文件](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/pnpm-lock.yaml)

## 本轮结论与验证优先级

优先检查自定义 SDK 的 `session/wait`、Team 消息结果与重试假设、已删除的 `both`、Python PTC 依赖接线及目录／权限分离。之后再看模型路由、插件版本和状态 UI。完整任务、预算和企业隔离仍需业务层补足。

基线发现的默认 Session Log 外发与第三方记忆边界**不是本次新增缺陷**；详见 [FINDINGS](../FINDINGS.md)。目前维持“借鉴、验证、观察”，不据本次发布提升为生产采用。没有向上游提交 issue/comment，也没有运行任何模型或 dsh 程序。
