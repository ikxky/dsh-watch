## Search／Fetch：配置开启之后的明确边界

**官方说明＋源码核实。** 新提供者共用凭据与 API 基址。启用新 API 后，`sendOriginalQuestion` 默认 true；Search 除 query 之外，会把发起会话最近一条用户提示的文本合并、折叠空白、截取128个字符，以 `ori_question` 发送。会话外或没有对应提示时不带该字段；显式 false 可关闭它。这是所选提供者的配置行为，不是所有用户默认外发，更不是本项目已复现的漏洞。[Search／Fetch 固定说明](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/web/web-deepseek-api/README.zh.md)、[请求与默认配置源码](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/web/web-deepseek-api/src/index.ts)、[Search 字段构造](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/web/web-deepseek-api/src/search.ts)

Fetch 把请求 URL 交给远端服务，返回 Markdown；适配结果的 HTTP 200 和请求 URL 不代表目标页面真实状态或最终重定向地址。查询与目标 URL 约束由远端执行；API 传输层拒绝重定向与“目标页面是否发生重定向”是两个问题。失败不会自动重试或回退到其他提供者。需要精确来源验证或本地抓取策略的上层产品，应分别处理这两个边界。[Search／Fetch 固定说明](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/web/web-deepseek-api/README.zh.md)、[Fetch 源码](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/web/web-deepseek-api/src/fetch.ts)

直接 API 不消耗辅助模型 token，但结果进入上下文仍有 token 成本，抓取服务计费独立；不能据此推导整项任务更便宜。Search／Fetch 不产生辅助请求事件，工具调用与结果仍进常规会话记录；不能只靠辅助请求统计审计这条出站路径。官方文档中的2026-10-16探测是上游记录，不计作本项目实测。[Search／Fetch 固定说明](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/web/web-deepseek-api/README.zh.md)

## 插件、显示与可靠性

自定义市场随包关闭，默认 `indexes: []`，没有官方市场；添加源前不发送市场请求。Creator 的 `plugin_market` 只读发现，安装由独立插件管理操作完成。索引无签名，兼容性标签来自声明；宿主代码、安装脚本和跨会话影响仍须分别判断。插件无独立发布时按本页主 tag／commit 和 manifest 版本记录，不编造插件独立发版史。[自定义市场](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-market/README.zh.md)、[可选市场组合](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/experimental/plugin-market-bundle/README.zh.md)、[安装工具权限](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/tools.ts)

alpha.3 的已发送凭据遮罩属于显示层，不是日志、模型请求或第三方出站的脱敏承诺；意外退出后的“任务已停止”显示也不证明外部动作已回滚。恢复、插件热替换与 alpha.5 技能菜单／终端修复按各自 release 归属记录，没有测得故障率改善。[alpha.3 release](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.3)、[alpha.5 release](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.5)、[Web 显示遮罩配置](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/bundle/web-app/cordis.patch.yml)

alpha.3 还新增显式 `persistent-in-memory` PTC 模式，默认仍 `per-call`；内存不落盘，重启、取消、超时会清空，无空闲过期机制。Azure 提供方名称需由 `azure-openai-responses` 迁为 `azure`；rc.2 pi-ai manifest 为 `^1.1.0`。`--from-default-profile` 重建会替换配置、插件与设置。以上分别是运行方式、模型兼容和配置迁移条件，不当作完整能力成熟度提升。[PTC 内存模式契约](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/ptc-runtime/ptc-runtime-node/README.zh.md)、[pi-ai manifest](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/llm/llm-pi-ai/package.json)、[alpha.3 发布](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.3)
