## 实质变化

**验证执行与数据边界；观察实验功能。** 这个节点把 SSH 远程工作区、MCP resources、后台调用入口与 Node PTC 进程执行带入同一发行版本。更容易漏掉的是默认变化：DeepSeek 协议改为 Messages，Session Log 请求附带功能由默认关闭改为默认开启。功能变多与适用范围扩大不能直接推出安全性或企业就绪程度提高。[R]、[日志旧配置][S1]、[日志新配置][S2]

## 六维增量

| 维度 | 相对 v0.1.5-rc.2 的主要变化 |
|---|---|
| 产品、交互、部署 | Web 增加侧栏终端；Headless 接受 stdin、恢复 session 和逐行 JSON 事件；SSH 让本地 dsh 操作远程文件、命令及 PTC。Browser／Computer Use 为实验入口，不能当作已验证的无人值守能力。[R] |
| Loop、规划、并行、恢复 | `agent/session-start` 换为异步串行 `agent/created`，首次请求等待初始化；Team 统一 `spawn_teammate`；Shell／sandbox 准备接口变为可取消异步，准备时间计入超时。[R] |
| Context 与 memory | Session 写入格式仍是3，没有因产品版本升级而再次变更。新增图片 offload 记录；同步历史接口进入弃用。没有足够证据把此版称作新的长期记忆架构。[格式常量][S3]、[R] |
| 插件、Skills、MCP、模型、SDK | MCP 升级 SDK v2并支持资源及 URI 模板；PTC 包／服务改名、工作流改为 `workflow-ptc`，移除内置 E2B 后端。DeepSeek 默认选 Messages，但源码仍接受 Chat Completions；仅 Messages 的强制边界要到 v0.1.7-alpha.1。[R]、[协议配置][S4] |
| 身份、审批、沙箱、审计 | Node PTC 每次启动新进程，接入会话文件策略、输出和堆限制，生成代码的 `process.env` 为空。Auto review 新增但为实验能力；Python PTC 当时明确没有文件沙箱，也没有默认 profile 启用。[Node 契约][S5]、[Python 契约][S6] |
| 日志、异常、升级、成本 | Session Log schema 默认值 false→true，基础 bundle 挂载；热更新取消事务回滚，解析失败保留旧配置，但激活失败可能部分生效。可选插件失败与必需插件失败区分处理。额外评审／工具能力没有带来已验证的统一成本上限。[配置][S1]、[S2]、[组合][S7]、[R] |

## 升级影响

**源码核实：**日志默认翻转发生在这两个相邻已发布 tag 之间。release 将会话事件附带声明为实验性开启；实际是否出站仍取决于使用的适配器、请求及显式配置。企业不能假设旧的默认关闭会随升级保留，需区分没有设置、显式 false 与界面保存的配置。[S1]、[S2] 本轮没有网络记录，也不知道服务端保留与删除效果。

**官方限制：**Node 的文件约束、输出和堆上限并非整个进程树的 CPU／内存或网络隔离；清理也可能晚于运行超时。Python 当时的资源限制同样不能补出不存在的文件沙箱。[S5]、[S6] 后来的 Python 文件策略接入应归属 [v0.2.1-alpha.2](v0.2.1-alpha.2.md)，不可倒填到本版。

**推断：**迁移成本较高的对象是自定义 PTC 插件、E2B 配置、初始化 listener、远程路径消费者和旧模型网关。可**借鉴**首次请求等待初始化、跨进程运行与显式资源限制；在执行位置、凭据、取消、默认出站清楚前，**跳过**生产运行时采用。无需运行即可继续检查的下一项是 v0.1.7 对协议和格式的收敛，见 [演进总览](../EVOLUTION.md)。

## 插件专项补充 · 2026-10-13

base 新增 `image-offload`、`mcp-resources`、Node PTC 与 `workflow-ptc`，移除 `workflow-worker-thread`，并将 Ralph 默认关闭；Web 增加终端服务及界面。需同步检查 `agent/created` 初始化、PTC 名称、工具暴露和日志默认值。四个 npm 归档可取，所查 YAML 一致，但内部 dsh 依赖仍为版本范围。
