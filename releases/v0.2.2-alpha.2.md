## 默认HTTP抓取：网络范围实际扩大

**源码核实／P1验证。** base仍挂载 `web-fetch-http` 并选择 `fetchProvider: http`，但提供者删除公网地址筛选与连接固定，使用进程级dispatcher和系统解析器。loopback、私网及云metadata地址不再由该提供者按地址类型阻断，实际可达性仍受部署网络及目标服务要求约束。URL仍限制HTTP(S)、不允许内嵌凭据，保留同源重定向及字节、字符、超时上限；匿名、有界不等于限制内网访问。[基础组合](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/bundle/base/cordis.patch.yml)、[HTTP Fetch 契约](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/web/web-fetch-http/README.zh.md)、[HTTP 传输实现](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/web/web-fetch-http/src/provider.ts)、[URL 策略](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/web/web-fetch-http/src/policy.ts)

固定base注释与policy文档注释仍写公网验证／连接固定，与同commit的README及实际调用路径冲突。这里并列记录冲突，以实现与包契约解释当前条件，不以旧注释声称防护仍在。官方要求部署另设网络控制，或在工具pre-execute前限制目标；文件沙箱不替代此责任。没有发送内网请求、访问metadata或复现漏洞。[HTTP Fetch 契约](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/web/web-fetch-http/README.zh.md)

这与rc.2新增的可配置DeepSeek Fetch API是两条路径：本次改变的是本地 `http` 提供者，不能用“新版API需启用”淡化默认HTTP组合的范围变化。

## 外部委派：OAR不继承DSH执行边界

OAR实验提供者和工具有固定源码，但不在 `OPTIONAL_BUNDLES` 或 `ON_DEMAND_BUNDLES` 中；不能写成默认提供或官方一键可选组合。需显式添加依赖和profile配置，并备妥已安装、已认证的原生CLI。官方按需组合仍只有Claude Code和Codex，不能与OAR路径混同。[OAR 边界](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/experimental/subagent-oar/README.zh.md)、[官方供给清单](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/util/official-bundles/src/bundles.ts)

原生进程由OAR管理，不应用DSH子进程沙箱或受管理后代清理，也不将原生审批转发到DSH。Claude省略原生权限参数会继承OAR默认权限绕过；示例的显式权限参数不能推广到空配置。此路径不创建DSH子Session，只有单次文本任务、标识和最终结果，无继续／恢复、进度流、完整原生轨迹或副作用回滚保证；取消前更改会保留。[OAR 边界](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/experimental/subagent-oar/README.zh.md)

**P1验证：**上层平台需单独定义原生权限、账户、网络、超时、结果核对和日志保留。现有内置子代理的支持状态不因出现外部适配器自动升级；本项目未启动任何CLI或模型。

## 升级兼容：接线、协议和取消语义

| 迁移面 | 已核条件与接入检查 |
|---|---|
| Node | CLI要求 `>=24.9.0`；先核运行环境，不能只更新包名 |
| 工具执行 | native／PTC拆成Agent作用域执行器，PTC用overlay；旧 `tools.mode`、`DSH_TOOLS_MODE`及 `tools.resolve/executable` 消费者需迁移 |
| Session投影 | 异步 retained handle与释放责任；旧注册disposer／key读取仅保留弃用兼容，审批恢复需服务接线与激活等待 |

| SSH | rc.4协议2→alpha.2协议3；helper用 `z.literal(SSH_PROTOCOL_VERSION)`验证并返回入口／bootstrap摘要。client、helper及自部署worker／bootstrap须同步升级 |
