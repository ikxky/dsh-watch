## 模型目录：版本固定仍需记录发现时的条件

官方 API Key 路由在跟随目录时，以 `x-api-key` 和 harness User-Agent 请求 `https://api.deepseek.com/models`，拒绝重定向；没有密钥不请求，发现返回空目录。自定义 origin 或自定义 `models` 使用配置目录，不探测推理端点。首次访问最多等待默认5000毫秒；已加载目录超过默认600000毫秒后，由下一次访问触发后台刷新，空闲时不轮询。失败或空响应保留旧目录，尚无成功目录时回退当前构建的内置目录；401仅使这次加载失败。[API Key 动态目录](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/llm/llm-deepseek-api-key/README.md)、[API Key 实现](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/llm/llm-deepseek-api-key/src/index.ts)

目录声明的最低客户端版本参与准入；不满足或不支持的条目在推理请求发出前拒绝，错误为 `CLIENT_UPGRADE_REQUIRED` 或 `MODEL_UNSUPPORTED`。目录未列出的模型 ID 仍透传，不能把门槛理解为所有模型的远程可用性验证。编辑模型页目录会停止跟随；恢复默认会重新加载。保存的目录若只等于旧版内置目录，升级后也可能被视为自定义而停止跟随。[API Key 动态目录](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/llm/llm-deepseek-api-key/README.md)、[模型准入源码](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/llm/llm-deepseek/src/listed-catalog.ts)

**推断／P1验证：**接入产品除 runtime 版本，还应记录官方／自定义路由、目录策略、最近加载结果与拒绝原因；目录出现不等于模型调用成功。动态容量和输出上限也不等于整项任务预算。

## 草稿与授权：入口更近，执行仍需用户决定

新插件随 Web 组合默认挂载。浏览操作仅打开插件主列表；创建操作以 Creator preset 新建或复用合适空白会话，已有文字、引用、附件保留，区域请求另起段追加。它不发送消息，也不直接安装插件。缺少 Creator preset 或目标 Workspace 时按现有失败流程提示，不能把一个按钮视作可用插件生成服务。[Web 默认组合](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/bundle/web-app/cordis.patch.yml)、[更多菜单与草稿](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/client/ui-entry-customization/README.zh.md)、[入口回调源码](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/client/ui-entry-customization/src/client/index.ts)

## 新会话复用：草稿恢复与配置更新需要分开

rc.2 的新会话每次创建 Session／Agent，遗留空白会话不显示在树中，未发送草稿难以返回；rc.3 改为优先复用空白会话。`startSession`、`openWorkspace`、`connectWorkspace` 均受影响。若复用会话的 Agent 仍已加载，会保留创建时的 preset 装配，新会话不再保证使用最新定义。[空白会话迁移指南](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/docs/upgrade-guide/v0.2.1-rc.2/new-session-blank-reuse/guide.zh.md)

**P1验证：**修改预设后，须使用修改后装配的会话；官方给出的路径之一是重启 Host 后恢复空白会话。要求明确 preset 的集成应传入 `agentPreset`，避免接管其他 preset 的草稿。此处是生命周期迁移，不是实测权限绕过，也不证明已发送任务的崩溃恢复改善。指南目录名含 rc.2，正文实际描述从 rc.2 行为迁移，本次归属以固定 diff 和 rc.3 release 为准。

## Desktop 采集边界

本次扩展导航来源、更多菜单动作、被接受的模式切换，以及发送时 `is_new_session`／`agent_preset` 等字段。不采集第三方入口标识、自定义预设名称；自定义预设按 `other` 表达。官方字段排除提示词、模型回复和凭据。Desktop 默认启用产品埋点，普通 Web 不装配；关闭新采集不清空已排队导出，与会话反馈和 Session Log 是不同通道。[Desktop 事件边界](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/client/product-analytics/README.zh.md)、[事件类型源码](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/client/product-analytics/src/events.ts)

**P1验证／P2观察：**需要更新数据字段清单，但不能写成会话全文上传。点击、模式切换和发送次数不是验收成功率、业务成果或任务总成本；仓库不提供数仓表或看板，指标语义由上层产品负责。
